Orpheus' Knowledge

After stealing the laptop and coming back to the Raguel and Covenant base, you will be given a task to decode the security systems of the laptop, otherwise data is not accessible. The security breach is done using the dialog options. You must select which line you want to modify and then select available options. First, you must modify the first line to "accessGranted = true;". Then you must select line 8 and select "userActive = true;". Next step is selecting line 11, changing the code to "encryptionActive = true", which will unblock line 15. In the line 15 you need to select "dataAllowed = true;", which enables you to log in into the device.
